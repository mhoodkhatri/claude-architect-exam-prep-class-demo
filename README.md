# Claude Architect Exam Prep

My study notes and practice material for the Claude Architect certification exam.

This repo contains only Markdown files: notes, summaries, practice questions and a study log.

## Goals

- Cover every topic on the exam guide
- Write my own notes and examples instead of copying material
- Practise with questions and track weak areas until they're solid

## Planned structure

```
claude-architect-exam-prep/
├── README.md           # This file
├── study-plan.md       # Schedule and milestones
├── syllabus.md         # Topic checklist the nightly lesson workflow works through
├── lessons/            # One lesson per night, written by Claude Code at 9 PM PKT
├── notes/              # One file per exam topic
├── practice/           # Practice questions and answers
└── log.md              # Daily study log: what I covered and what to revisit
```

## How I use this repo

1. Pick a topic from the study plan.
2. Write notes in `notes/<topic>.md`.
3. Test myself with questions in `practice/`.
4. Record progress and gaps in `log.md`.
5. Commit after every study session.
