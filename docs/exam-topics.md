# Exam Topics Tracker

This doc explains the table in `exam-topics.md`, which tracks each exam topic I need to study.

## Columns

| Column | Meaning |
|--------|---------|
| Topic | Exam topic name |
| Priority | `high`, `medium` or `low`, based on exam weight and my confidence |
| Status | `not started`, `in progress` or `done` |
| Target date | Date I plan to finish notes and practice for the topic |

## How to update

1. When I start a topic, set Status to `in progress`.
2. When notes and practice questions are done, set it to `done`.
3. If I slip past a Target date, move it and note why in `log.md`.
